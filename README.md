### Hi, I'm Jeff

I'm a full stack developer and marketing technologist. I build automation that keeps a business running without anyone babysitting it. Most of my work is GoHighLevel, n8n and Claude, plus the Meta and Google ads that feed them, for marketing agencies and home service businesses.

I'm ops lead at a white-label HighLevel agency, and I run the [HighLevel Philippines community](https://www.facebook.com/groups/highlevelphilippinescommunity), around 20,000 members.

**A few things I've built**

- **A contact sync for a marketing agency.** About 438,000 contacts from 1,600 GoHighLevel accounts, kept up to date every 15 minutes, with a checkpoint per account and recovery if a run stops halfway.
- **My own MCP server for GoHighLevel.** Claude plans, writes and publishes workflows straight into an account, and nothing goes live without my confirmation.
- **Joven, my job search agent on n8n.** Claude scores each post and drafts the reply, and I approve it on Telegram before anything sends.
- **FrontScale AI.** An operations platform for pest control and lawn care, with AI quoting, CRM and dispatch. Still building.
- **HighLevel marketplace apps.** OAuth installs, SSO into embedded pages and signed webhooks.

Most of this code is private because it runs on client accounts. The video above shows two of the builds on real screens.
